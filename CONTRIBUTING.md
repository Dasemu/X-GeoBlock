# Contributing

Contributions are welcome. Keep the extension dependency-free unless a new dependency has a clear maintenance or security benefit.

1. Create a focused branch.
2. Run `npm run check`.
3. Load the repository as an unpacked extension and test a timeline, infinite scrolling, settings changes, cache clearing, a followed account, and a blacklisted account.
4. Describe any X markup samples used to update the parser, removing personal or session data first.

Do not commit captured X pages, cookies, authentication headers, or user cache data.
